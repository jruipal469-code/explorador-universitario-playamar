# Explorador universitario · Playamar

## Publicar en GitHub Pages
1. Descomprime este ZIP.
2. Crea un repositorio en GitHub y sube index.html, .nojekyll y este documento a su raíz. No subas el ZIP sin descomprimir.
3. En Settings → Pages, selecciona Deploy from a branch, la rama main y la carpeta / (root). Guarda.
4. GitHub mostrará la dirección publicada cuando termine el despliegue.

El explorador es autónomo: sus estilos, imágenes, fuentes y datos están incluidos en index.html. No necesita instalación, compilación ni plugins.

## Botón de regreso
El botón «Volver a la página anterior» abre la página de procedencia en la misma pestaña, también cuando el explorador se abrió en una pestaña nueva. Si el navegador solo comunica el dominio de origen, volverá a ese dominio. Si no comunica procedencia (acceso directo, marcadores o enlaces sin referente), volverá a:
https://blogsaverroes.juntadeandalucia.es/brujulaplayamar/buscador-universitario/

La procedencia se conserva durante la sesión de esa pestaña para que el regreso siga funcionando tras recargar. No se envía a un servidor. Si el navegador bloquea el almacenamiento, el enlace continúa funcionando con la procedencia disponible o la alternativa de WordPress.

## Mantenimiento
Se ha conservado el contenido, los datos y las fuentes de la versión local existente. Empaquetado el 2 de noviembre de 2026; no supone una actualización de ponderaciones. Comprueba la vigencia de los datos antes de cada curso.

Para garantizar el regreso a una página exacta, añade al enlace del explorador el parámetro `?volver=` seguido de la dirección de origen codificada. Ejemplo (sustituye la dirección inicial por tu URL de GitHub Pages):

https://TU-USUARIO.github.io/TU-REPOSITORIO/?volver=https%3A%2F%2Fblogsaverroes.juntadeandalucia.es%2Fbrujulaplayamar%2Fbuscador-universitario%2F

Este parámetro tiene prioridad sobre la procedencia que comunique el navegador. Solo se aceptan direcciones HTTPS sin credenciales.
